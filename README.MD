## About the project

Simplest website possible, using the most basic languages of HTML and CSS, this site will represent the visual part of a fictitious company to hire services, their selection, and simple form to reserve, and a contact section

## Structure

The project will be realized with:

* this README.MD file.
* an index.html in root
* an img folder with visual resources
* a styles folder with the main .css linked and root, header, main, footer styles files imported

The HTML consist in three sections

1. Header with logo, motto, and nav.
2. Main with three subsection: about, reserve and contact.
3. Footer with my name and my github link.


## Workflow

To show tidyness and order, it is important to keep a good structure and workflow, even in the smallest projects, to help readiness, understanding and scalability of the work.

I'm using this to help me:

* Develop a template in Exvalidraw to design the visual of the site.
* git and github, with separation of branches, where main will only have this readme, develop will host the finished code, and branch feature_myname to host the code in progress. When site is finished I will make a pull request to merge this featur branch into develop.
* continuous use of commits, at least one per section coded.
* Use of comments and BEM naming method.
* Use of Trello to register and notify every step made.
